# DreamPoly

Анализ сновидений DreamBank: лексика, эмоции и темы. Ноутбук — `DreamPoly.ipynb`.

Архив `data/raw/dreambank.tar.xz` уже скачан. Зависимости — в `requirements.txt`.

Данные: DreamBank, Adam Schneider и G. William Domhoff. Снимок Zenodo https://zenodo.org/records/18159468 (5 января 2026), CC BY-NC-SA 4.0. Только некоммерческое использование, с указанием авторства.
